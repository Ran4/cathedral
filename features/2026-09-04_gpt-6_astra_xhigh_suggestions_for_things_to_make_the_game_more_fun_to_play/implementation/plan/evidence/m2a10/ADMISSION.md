# M2a10 social admission — 2026-09-08

Status: Implemented, independently reviewed and accepted (2026-09-08). Existing component scope; complete M2/M3 remain pending and global caps are unchanged.

The common lexical meter sees the complete borrowed shape before exact owner cloning and every original raw byte before typed parsing. A cohort retains at least `4096 + 4*E + 3*J + 65536` bytes. E charges 512 bytes per object/array, 64 per key/scalar/string and twice each encoded string byte. J includes padding and escapes. Exact DTOs and candidate moves retain the raw-input charge even when canonical reserialization is much smaller. Error/disposal releases the lease. Export/encode stream borrowed closed records directly; there is no production serde_json::Value, temporary World, geometry index or context hash rebuild.

The 64 KiB owner allowance is fixed parser/serializer/recursion/error and one inline row working state; validation allocates no secondary index. Heap-owned IDs, including temporarily decoded invalid strings and the two endpoints in a malformed warm row, are paid by lexical E/J and the four-E bound, not asserted to fit within 64 KiB. Serde's escaped-string scratch and geometric buffer capacity are covered by the three-J term. An owned decoded string is no larger than its decoded input byte count; clone creates an exact string length. Unknown/duplicate-error strings can refer to malformed input, so the E/J allowance remains charged through refusal.

All record fields are closed and required, including nullable fields. The scalar config-bit object and unit idle-mode enum reject unknown variants/fields/duplicates. Warm pairs decode from closed {a,b,at} rows directly into the final BTreeMap, rejecting self, reversed or duplicate pairs and stopping after the 25,000th retained pair. Engagement witnesses parse through a direct unique-set visitor. Novelty memories parse through a direct unique-map visitor into final Memory records with no intermediate row Vec or Value. Witness/memory count validation follows typed parsing; malformed overcount inputs remain bounded by aggregate E/J before any allocation. The proof must therefore cover these rejected parsed shapes too, not assume successful format caps during parsing. A 25,001-memory refusal and a two-million-byte invalid key exercise that path.

For BTree maps/sets the first leaf allocates eleven slots even for a singleton. Count the empty decoded map as no node; clone of any empty retained runtime map returns a new empty map in the pinned standard library. For n>0 use the conservative node count `floor((n-1)/5)+1`, including full eleven-slot first node, 64-byte header allowance and twelve 8-byte child pointers. Strings are charged separately. The retained serialized view never clones its inputs.

An ActorId witness slot is 24 B. A conservative full sparse node costs 424 B, already covered by the outer witness-list 512 E for a singleton; later nodes cost at most 84.8 B/entry plus short strings, comfortably inside four times the 64 E+encoded-string contribution per witness. Warm pair slots and Novelty map slots each contain owned key(s) and numeric/private state; layout tests pin actual sizes. Warm rows contribute an object 512 E, three 64 E field names and three scalar/string contributions plus encoded ID bytes, while the outer sequence adds 512 E. Novelty rows contribute a 512 E object plus three field keys/values, its actor key and the outer 512 E map. These charges cover sparse first nodes, later node growth, inline owner/DTO/candidate layouts and string content with substantial room. Malformed count overflow follows exactly the same shape cost, independent of admitted 25,000-row maxima.

Conversation's three independent optional records and tokens are inline; absent options still contribute scalar 64 E and field 64 E each. Present engagement has its own object, actor/time/flag/witness fields and set; invitation/focus each have a closed object. The Engine component adds player ID, two raw-float objects, mode/flags and the three nested raw owner records exactly once. Candidates contain only their admitted DTO; moving into a candidate builds no additional maps. Max tests cover 128 witnesses, 25,000 warm pairs with 50,000 independent historical endpoints, 25,000 memory rows and sparse 0/1/2/5/6/11/12 shapes, separate from measured world sizes.

Logical anchors are not normalized against host origin. Opaque visit/context salts never allocate or become clocks. Raw max_actors is decoded to usize by checked conversion only and is never used for allocation during validation. Invalid pair, identity, anchor, token order, raw bits, unknown/duplicate/missing nullable fields, exhausted cohorts and deep inputs all release their reservations.

The six production-workload phases are borrowed preflight, exact export, encode, raw decode/validation, repeated candidate validation and disposal of both cohorts. Real navigation/content builds authored 520 and successfully placed +2000/2520 Engines. Ordinary named player speech submits a prompt, an explicit completion addresses player and a real nearby peer, and ordinary attention leaves partial focus at capture. No private Engine/social or World edit manufactures the timed state. Counts, actual submitted actor/prompt bytes and exact speech input/output witnesses are retained for every repetition. Rare/MAX/expiry/nonfinite and malformed maxima are deterministic tests, not timed-world claims. Component timing does not certify full-save, host-frame, maximum-shape or rendering acceptance.
