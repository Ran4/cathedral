All six coats survive. Dog identity must satisfy the existing ID policy (nonempty, at most 128 Unicode scalars, no controls), not a dog_ prefix or token syntax; spaces and Unicode are valid. Identities are unique within the ordered dog vector, without requiring an authored membership or disjoint spelling from character IDs. Public changes to name/description/body/home/leash/position/yaw/speed/gait survive; they are not replaced with PACK defaults.

Numeric fields are finite, with the established ±1,000,000 city-coordinate bound for base, position and waypoints. Signed build/leash/speed/gait/rest and unnormalized yaw remain supported. No route walkability, path/base leash constraint, Y-plane requirement, speed cap, path/rest coupling or gait modulo is invented. Finite extremal arithmetic and all-consumer future motion/accounting horizons remain complete-envelope gates; format validation alone does not establish them.

An ordinary arrival consumes its last waypoint but leaves positive last speed. The following tick clears speed and must publish the stop once. A planted turn changes yaw while speed remains zero; partial acceleration preserves its exact path and gait. The rest for a successful drift is rolled before arrival; a failed drift increments epoch and resets rest to four seconds. Negative rest, signed direct dt and u64::MAX epoch preserve the existing stepping behavior. Epoch uses wrapping_add in ordinary source, so no monotonic headroom restriction is valid.

Private tests independently prepare both owners, scramble all covered mutable fields and resolver slots, install only covered fields privately, then assert immediate canonical equality before ordinary steps/polls. They exercise all motion boundaries, wrapped successful/failed drifts, later arrivals/decisions, initial/rest/stop/empty publication and full ordinary Engine polls with equal covered state and revisions. The independent public tests cover path/epoch equality through planted turns and future drifts, edited/reordered identities, positive-speed stop, exact nav mismatch, unadopted backbone, strict/raw admission and World/config nav divergence.

movement_now governs human movement, dogs and the post-slice custody follower. With config.nav=None, tick_movement returns before advancing the anchor or publishing dogs. Historical backwards/coarse debug polling also prevents a universal movement_now<=boundary or residual<TICK constraint at this component seam. Complete production capture must bind the shared anchor to the accepted player sample, host residual and ordinary time policy; other Engine owners must reference this one value rather than capture a second unsynchronized copy. Round cadence, custody state and human motion remain their own preserved owners.

No decode calls seed_pack, drift_path, route_between, Engine::new, poll or step_dogs; constructors occur only in test/probe setup. Full envelope build/target/toolchain/DefaultHasher compatibility, immutable resolver composition, initial host republish, pending-work restoration and full Engine hydration remain unimplemented. Ward moods/Night and remaining Engine configuration/cadence/attention/conversation/speech/scheduler owners remain separate cuts.
