# M2a12 continuity admission — 2026-09-08

No budget changes: 128 MiB encoded J, 128 MiB expanded E, depth 64, shared Running/Save/Load/retiring ceiling 1 GiB. Each attached cohort reserves at least `4096 + 4*E + 3*J`. Additional validation working bytes are **zero**, because this owner creates no heap validation index, catalog resolver, temporary candidate or registry. Preflight/export stream a borrowed view before copying; decode scans complete raw bytes before typed allocation. Raw padding and escaping remain charged for the candidate lifetime. Canonical reserialization cannot shrink the lease. Disposal drops authority before releasing its reservation.

The existing lexical meter charges 512 E bytes for every object/array, 64 for every scalar/string/key, and twice encoded string bytes. Four expanded copies cover typed DTO, retained candidate/copy and scratch. Three raw encoded copies cover original input plus geometric serde_json string scratch; raw J includes whitespace and escape spelling. The 4096 bytes cover fixed framing. Malformed unknown-field names and other input-derived error text are variable allocations covered by E/J, not by a claim that all error strings fit 4096 bytes. Recursion is stack-based and depth-limited; this component's closed records have shallow fixed structural depth.

Floor validation checks len <=32 before scanning IDs pairwise. At most 496 borrowed string comparisons allocate nothing. It never builds a set or sorts authority. The Engine player lookup borrows the supplied BTreeMap and performs contains_key; no BTree node is allocated or cloned. Text limit and diagnostic count checks borrow existing slices. There is no ledger validation scratch in this component.

Concrete types on the pinned 64-bit toolchain are checked by the focused layout tests. AwaitedSpeech is at most 64 bytes; each wire row contributes a 512-byte object, three field keys/scalars and a nested deadline record, well above even doubled Vec capacity. Floor, DTO, Engine DTO/View/Config fit their corresponding 512-byte outer-object charge (see final emitted layout numbers). Vec<String> and Option<String> contain 24-byte strings: geometric doubling needs at most 48 bytes per nonempty row versus at least 64 E per string, and the four-element singleton capacity is covered by the array's 512 E. Empty string rows are still 64 E each. String clones and Vec clones copy populated lengths, not historical excess capacity. Floor copy collects an exact-size iterator of 32 or fewer rows and clones only populated strings. Source-pinned standard-library excerpts cover RawVec growth, String/Vec/slice cloning and exact-sized Vec collection. Sparse historical live capacity does not inflate exported state.

SpeechEventId remains an arbitrary exact string, including empty strings, controls and Unicode. The supported format bound is 65,536 UTF-8 bytes per ID and 32 unique awaited rows, independently of the character roster. Startup diagnostics allow 25,000 ordered strings, each at most 65,536 UTF-8 bytes; the nullable-but-mandatory startup message shares that byte limit. These are supported-save limits, not newly added ordinary runtime truncation rules. Combined maximum counts and text lengths still must fit aggregate E/J/shared budgets. Max-shape tests combine 32 maximum event IDs and separately 25,000 diagnostics, one maximum diagnostic and a maximum startup message. One-over shapes refuse; malformed oversized typed collections are already raw-admitted before construction.

Closed V1 records reject duplicate, missing and unknown keys, wrong variants/types, and missing nullable fields. Public DTOs implement Serialize only; typed deserialize is private behind admitted decode. Raw float records preserve IEEE bits exactly and reject malformed/missing/duplicate bits fields. Pacing uses explicit `never`/`at` variants, not JSON infinity. No ordinary owner mutation, constructor, poll, IO, clock, thread or service call occurs in production decoding/candidate conversion.
