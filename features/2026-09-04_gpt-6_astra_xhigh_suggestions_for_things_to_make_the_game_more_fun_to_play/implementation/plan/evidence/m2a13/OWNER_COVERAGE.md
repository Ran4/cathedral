# Speech interruption owner

The component preserves sim-owned semantic input for load interruption, without creating an executable router. Its mandatory purpose `public_player_speech` classifies today's router input; status `interrupted_unsent` explicitly requires a new intentional submission. Current router fields contain no proposition version or learned-record selection. Those must be owned by future/host draft state; this component invents neither. Original recording spatial_seq and pre-accepted payload pose are absent from TranscriptionTask, so its projection cannot recompute the original command payload digest. The full envelope must reconcile owner/category and exact ledger payload binding.

Accepted rows serialize all batch tasks in original order followed by parked tasks in original order. Required source tag and optional deadline enforce that canonical partition. Reused basename/request strings do not merge rows or require uniqueness. Captures and streams retain their independent source vectors; neither is inferred to be an accepted task. Every present semantic ID binds an issued protected root and an exact retained receipt, including affected order and bitwise receipt time. Receipt snapshot is explicitly closed and uses prior receipt text/count/principal rules. Terminal states are reachable via public ledger advance while a task remains owned; normal completion projects that outcome and releases the root without another say. This component preserves that fact and does not terminalize anything.

The candidate owns only the admitted projection and offers borrowed read-only rows. It has no router getter, production installer or adoption API. Export/preflight streams borrowed rows before copying. Capture, decode and candidate validation construct no Engine, World or SpeechRouter and never call normal resolve_transcription/apply say, on_audio_abort, submit_batch, provider, service availability, poll or IO. The source field destructure makes new router fields require another explicit disposition.

M2c still must consume these inputs with exact Floor, ledger and shared roots to terminalize only unfinished accepted recording obligations, release ownership correctly, discard old recording holds/execution, and publish unsent draft/status without replaying speech. Existing terminal receipts remain terminal. This owner does not certify owed committed presentation text: it must bind actual pending DomainEvent/EngineMessage/host text, never reconstruct text from TTS mappings or rerun say. M3 owns generation fences for every callback and dedicated initial publication without poll.
