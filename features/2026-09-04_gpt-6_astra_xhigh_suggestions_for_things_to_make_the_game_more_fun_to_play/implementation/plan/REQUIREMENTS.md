## Maintaining the record

Edit the catalog source when requirements or acceptance ownership change, then run `uv run evidence/plan_catalog.py --write` from this plan directory. Run without `--write` to check that the generated files match. An executed scenario needs its actual command/content version/result in the milestone's acceptance record; changing this table never certifies implementation.
