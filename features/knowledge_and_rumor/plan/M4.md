The player carries, keeps receipts, reads a journal, and — through `raise_word` — becomes the head of
a chain of claims that can be walked back to them. Plus the sim-side relevance re-heat, which is how
a cold fact comes back round with no verb at all.

Read `00_decisions.md` and `01_api.md` first. Decisions are cited `(D-n)`. Anchors are cited

## What lands

**Sim (Part A)**

- The player as a carrier: their own poll seat off `Engine::poll` (`PLAYER_CURIOSITY`, never
  `attention::curiosity_of`), and a **receipt** written at the one place a fact is ever learned.
- `LearnedHow` filled for real — `at` / `place` / `from` / `hops` / `tellings` / `wards` — plus the
  sentence the player actually heard, so a receipt survives its holding being evicted.
- `raise_word`: the one LLM mint path. `may_raise_word` as the sim's own gate; **both** occasion
  limbs (limb 1 a real `holds()` lookup, limb 2 the un-whitelisted `WorldEvent`); the
  one-raise-per-actor-per-office cap; the `(topic, subject, place, day)` collision reject; and every
  guardrail behind a **single constructor**, so none of them can be bypassed by writing a `Fact`
  literal at a call site.
- The relevance re-heat: bounded to `REHEAT_TO` **absolutely**, never `VOLUNTEER_HEAT / salience`.
- `EngineMessage::Journal { entries, standing }` + `JournalEntry`, dedupe-published on the hot channel.
- Two drive-mode pokes: `EngineCommand::{DebugSeedFact, DebugRaiseWord}`.

**Host (Part B)**

- `src/smart_actors/journal_ui.rs` — the `J` overlay on `inventory_ui.rs`'s pattern, plus the
  `PlayerJournal` resource on the `HotChannels` bundle.
- One standing HUD line (`JournalStandingText`) written by exactly one system, gated on
  `is_changed()`, hidden whenever nothing is live — which is the common case.
- The exclusion web in **both** directions: map, inventory, chat, settings.
- `raise-word` and `seed-fact` drive actions, documented in `.claude/rules/CATHEDRAL_DRIVE.md`.

**Not in M4.** Ward heat on the map, bells as amplifiers, the hearsay rung, the systemic readings, the
STRANGER token, and the quest-supplied **clock** half of the journal's two standing lines (nothing in
the base game holds a knowledge deadline; the `Vec` is the seam and it stays one entry short rather
than being faked). All M5.

**M4 adds no new probability.** The four constants it introduces are two caps, one real-seconds
publish cadence and one day-phrase ceiling; the pickup roll stays exactly the spec's
`curiosity × heat × salience` and every M4 decision — the gate, the cap, the collision, the re-heat,
the receipt — is a deterministic lookup. `done_when` asserts this with `grep`.

### A1. The four M4-owned constants

`src/knowledge/mod.rs`, appended to the constants block. These are **not** in `01_api.md`; M4 adds
them, and each carries its derivation, per the crate's rule that a number without one is a knob.
None of them is a probability.

```rust
/// What the player's receipt log holds. A busy ward carries at most
/// `AIR_PER_WARD_MAX` (24) facts and there are eight wards, so 64 is past two
/// full wards' worth of air and past anything one session produces. Evicted
/// oldest `at` first, then `FactId` — a total order, so eviction is
/// reproducible. 64 × (~40 B id + ~100 B sentence + 48 B of scalars) ≈ 12 KB,
/// on the world and in no snapshot.
pub const PLAYER_RECEIPTS_MAX: usize = 64;

/// How many receipts cross the wire, newest first. The overlay's panel is
/// 760 px wide and an entry is three lines, so 24 is already more than one
/// screenful: the cap is what a reader can use, not a byte budget.
pub const JOURNAL_ENTRIES_MAX: usize = 24;

/// Real seconds, like `STAGE_HOP_SECONDS` and for the same reason: the journal
/// is a *legibility* channel, not a sim cadence, so accelerating the clock must
/// not accelerate it. One rebuild a second of ≤24 entries is ~5 KB/s against a
/// 60 Hz poll, and the dedupe compare keeps the host's change flag quiet
/// between real changes.
pub const JOURNAL_PUBLISH_SECONDS: f64 = 1.0;

/// Past this the day phrase stops counting and says "a long while back".
/// Larger than `DAY_OFFSET_MAX` (3), so a garbled day never falls off the end
/// of its own vocabulary.
pub const WHEN_DAYS_MAX: i64 = 7;
```

`REHEAT_TO <= 0.15` and `REHEAT_TO > VOLUNTEER_HEAT` are asserted as arithmetic inside test A-15
(`the_relevance_reheat_is_bounded`) — the bound the spec's own test-contract bullet names.

### A1b. The occasion store — two fields, eight methods, all M4's

`src/knowledge/mod.rs`. Nothing before M4 declares any of this (D62). On `Knowledge`:

```rust

    /// un-offered ones past `OCCASION_LIFE_GAME_HOURS`; an offered one lives
    /// until its exchange lands or fails.
    occasions: BTreeMap<ActorId, Occasion>,
    /// `(game day, office, count)`, so the per-office cap needs no sweep.
    raises: BTreeMap<ActorId, (i64, Office, u8)>,
```

```rust
impl Knowledge {
    pub fn occasion(&self, actor: &ActorId) -> Option<&Occasion> { self.occasions.get(actor) }
    /// Overwrites: a person holds one occasion, the latest.
    pub fn note_occasion(&mut self, actor: &ActorId, subject: Option<ActorId>,
                         from: Option<ActorId>, game_days: f64) {
        self.occasions.insert(actor.clone(), Occasion { subject, from, at_game_days: game_days, offered: false });
    }
    /// `true` if there was one to spend. Called only on a **successful** raise.
    pub fn spend_occasion(&mut self, actor: &ActorId) -> bool { self.occasions.remove(actor).is_some() }
    /// Drops un-offered occasions older than the hour. An offered one is on a
    /// sheet in flight and outlives the clock (D34).
    pub fn expire_occasions(&mut self, game_days: f64) {
        self.occasions.retain(|_, occasion| {
            occasion.offered || occasion.at_game_days + OCCASION_LIFE_GAME_HOURS / 24.0 >= game_days
        });
    }
    /// `render_prompt_and_drain` rendered the verb onto this actor's sheet.
    pub fn offer_occasion(&mut self, actor: &ActorId) {
        if let Some(occasion) = self.occasions.get_mut(actor) { occasion.offered = true; }
    }
    /// That exchange landed or failed; the clock applies again.
    pub fn withdraw_offer(&mut self, actor: &ActorId) {
        if let Some(occasion) = self.occasions.get_mut(actor) { occasion.offered = false; }
    }
    pub fn note_raise(&mut self, actor: &ActorId, day: i64, office: Office) {
        let entry = self.raises.entry(actor.clone()).or_insert((day, office, 0));
        if (entry.0, entry.1) != (day, office) { *entry = (day, office, 0); }
        entry.2 = entry.2.saturating_add(1);
    }
    /// `RAISES_PER_OFFICE − count` when the stored `(day, office)` is this one,
    /// else `RAISES_PER_OFFICE`.
    pub fn raises_left(&self, actor: &ActorId, day: i64, office: Office) -> u8 {
        match self.raises.get(actor) {
            Some((d, o, n)) if (*d, *o) == (day, office) => RAISES_PER_OFFICE.saturating_sub(*n),
            _ => RAISES_PER_OFFICE,
        }
    }
}
```

### A4. `holds()` prefers the stored row over the seeded default

`src/knowledge/mod.rs`, in `holds_key`. M1 checks `seeded` first and returns `Held::seeded(fact)`.
M4 needs one actor to be **both** seeded and to carry a chain link: the raiser of a claim, whose
`seeded` set must be exactly themselves (the guardrail) *and* whose `from` must be the mouth that
armed them (A2). And A6's `set_heat_at` needs a seeded witness to be able to carry a re-heated
stored row. So:

```rust
pub fn holds_key(world: &World, actor: &ActorId, key: FactKey) -> Option<Held> {
    if !world.knowledge_enabled {
        return None;
    }
    let fact = world.knowledge.fact(key)?;
    // The store first, then the seeded default. A stored row can only ever be
    // *at least as close* as being there — `learn`'s fourth row refuses every
    // arrival to a hops-0 holder, so no seeded holder can acquire a farther
    // one — and this is what lets the raiser of a claim keep the chain link
    // back to the mouth that put the words in their head, and a re-heated
    // witness keep their re-heat.
    if let Some(held) = world.knowledge.stored(actor, key) {
        return Some(held);
    }
    if fact.seeded.contains(actor) {
        return Some(Held::seeded(fact));
    }
    None
}
```

Re-pin M1's T6 (`holds_answers_seeded_before_the_store_and_is_pure`) to this order: a stored row for
a seeded actor is only ever written by `seat_claimant` or `set_heat_at`, both hops 0, so the M1
assertion "a stray hops-4 row cannot be read as a garbled first-hand holding" becomes "`learn` refuses
a hops-4 row for a seeded actor (`Refused`) and the store never holds one".

`Knowledge::stored(&self, actor, key) -> Option<Held>` is the private-map read M1 already performs
inline inside `holds_key`; promote it to a named `fn` so both arms read one lookup. **No M1 test can
move**: no M1 fact has a holder who is both seeded and stored (`ashe.salt.short` seeds `fg2sh`,
`e9nan`; `vell.stall.pitch` seeds `dv8ll`, `p000x` — `03_assets.md:56-90`).

### A5. `render_plain` and `when_phrase`

`src/knowledge/mod.rs`. Both new, and both **hard-coded English in the sim**, not `strings.toml`: HUD
and journal prose is what the *player* reads, and `assets/prompts/` is the model's vocabulary. The
precedent is exact — `EngineMessage::ChalkStanding`'s labels are composed inside
`publish_chalk_standing` (`engine.rs:4116`) in English, and the law standing line in
`src/smart_actors/custody.rs`, both outside `PromptStrings`.

```rust
/// One holding as the *player* would write it down: the `own` or `said`
/// template with `{subject}` / `{place}` / `{day}` substituted through this
/// reader, and **no hedge wrapper**. The hedge ladder tells a model which mouth
/// it is speaking with; a journal says that on its own attribution line, and a
/// narrator in front of a remembered quote reads as a mistake.
///
/// Shares `substitute()` with `render_line`, so the unknown-people rule cannot
/// come to differ between the sheet and the journal.
pub fn render_plain(world: &World, reader: &ActorId, key: FactKey, held: &Held,
                    game_days: Option<f64>) -> Option<String>;

/// How long ago, in words. Shared by `render_plain`'s `{day}` and by
/// `JournalEntry::when`, so a receipt and its quote cannot disagree about the
/// day. `"at some point"` with no clock — the same "None means nothing ages"
/// tolerance `notices::expire` takes and `Held::heat` already has (D9).
pub fn when_phrase(at: Option<f64>, now: Option<f64>) -> String {
    match (at, now) {
        (Some(at), Some(now)) => match (now.floor() as i64) - (at.floor() as i64) {
            d if d <= 0 => "today".to_string(),
            1 => "yesterday".to_string(),
            d if d <= WHEN_DAYS_MAX => format!("{d} days past"),
            _ => "a long while back".to_string(),
        },
        _ => "at some point".to_string(),
    }
}
```

and, private to the module:

```rust
fn record_player_receipt(world: &mut World, player: &ActorId, key: FactKey,
                         telling: &Telling, game_days: Option<f64>) {
    let Some(fact) = world.knowledge.fact(key) else { return };
    let id = fact.id.clone();
    let place = fact.place;
    let ward = world.ward_at(world.characters[player].position_m());
    // Rendered from what they now hold, which after the merge is their version.
    let held = holds_key(world, player, key);
    let word = held
        .as_ref()
        .and_then(|held| render_plain(world, player, key, held, game_days))
        .unwrap_or_default();
    let hops = held.as_ref().map_or(telling.hops, |held| held.hops);
    let bit = ward.map_or(0u8, |ward| 1u8 << ward_ordinal(ward));
    // A plain `BTreeMap` on `Knowledge` (`01_api.md:426`), NOT one of the two
    // `Arc` maps: `holdings` and `air` are behind `Arc` because
    // `World::market_sale` clones the whole world on every catalog sale
    // (`inventory.rs:1298`, siblings `:916`, `:1141`), and `player_learned` is
    // one player's log, so there is nothing to share and nothing to `make_mut`.
    let receipts = &mut world.knowledge.player_learned;
    let entry = receipts.entry(id).or_insert_with(|| LearnedHow {
        word: word.clone(),
        at: game_days,
        place,
        from: telling.from.clone(),
        hops,
        tellings: 0,
        wards: 0,
        wards_seen: 0,
    });
    entry.tellings = entry.tellings.saturating_add(1);
    entry.wards_seen |= bit;
    entry.wards = entry.wards_seen.count_ones() as u8;
    // A closer telling replaces the provenance, exactly as the merge rule
    // replaced the view; a farther one leaves it alone. The first sentence
    // stands: a receipt is what you were told, not what you were told last.
    if hops < entry.hops {
        entry.hops = hops;
        entry.from = telling.from.clone();
        entry.at = game_days;
        if !word.is_empty() {
            entry.word = word;
        }
    }
    world.knowledge.bump_receipts_revision();
    evict_receipts(&mut world.knowledge);
}
```

Two borrow notes, both of which bite if ignored: `fact.place` and `fact.id` are read **before** the
`&mut` on `world.knowledge`, and `holds_key` / `render_plain` both take `&World`, so the `word` and
`hops` locals must be computed before `receipts` is bound.

`ward_ordinal(ward) -> u32` is `PlanningWard::ALL.iter().position(|w| *w == ward).unwrap_or(0) as u32`
(`lore.rs:66-76`, eight wards in declaration order), so `u8` is exactly wide enough.
`evict_receipts` drops down to `PLAYER_RECEIPTS_MAX` by `(at, FactId)` ascending — a total order, so
eviction is reproducible.

**One player.** `player_learned` is keyed by `FactId` alone, so it is *the* player's log and the
`Control::Player` test assumes exactly one. `assets/world/seed.json` gives one
(`{"id":"player","control":"player"}`), which is also why `PLAYER_CURIOSITY` exists at all (D26). Say

### A7. `reheat` — signature and body, both M4's

`src/knowledge/mod.rs` (D62; `01_api.md` lists it under M4).

```rust
/// Lift a cold fact back to just above the volunteer gate and no further, so a
/// revived story circulates without ever being as loud as fresh news. Called
/// when relevance seats a fact on a speaking turn — warming is a consequence,
/// not a decision, which is why it is a rule and not a verb.
pub fn reheat(world: &mut World, actor: &ActorId, key: FactKey, game_days: Option<f64>) {
    if !world.knowledge_enabled {
        return;
    }
    let Some(held) = holds_key(world, actor, key) else { return };
    let Some(fact) = world.knowledge.fact(key) else { return };
    if !fact.decays {
        // A standing fact's holders are at 1.0 and are never volunteered (D52):
        // "asked about" is the ONE way it reaches a ward's air, at REHEAT_TO,
        // in the ward the holder is standing in. `stir_up` creates the row
        // when absent and bumps `stir` (D28), so the ward re-rolls once.
        if let (Some(position), Some(now)) =
            (world.characters.get(actor).map(Character::position_m), game_days)
            && let Some(ward) = world.ward_at(position)
        {
            world.knowledge.stir_up(ward, key, REHEAT_TO, now);
        }
        return;
    }
    // Monotone: a warm fact is never cooled by being asked about, and a cold
    // one comes back to exactly `REHEAT_TO` and no further. A seeded witness
    // with no stored row gets one (A6's `set_heat_at`), so a 36-hour-old
    // arrest's witness revives like anybody else.
    if held.heat(game_days) >= REHEAT_TO {
        return;
    }
    world.knowledge.set_heat_at(actor, key, REHEAT_TO, game_days);
}
```

Three things it deliberately does not do:

- **No `/ salience`.** `REHEAT_TO` is an **absolute** heat, `VOLUNTEER_HEAT × 1.10 = 0.1309`.
  `VOLUNTEER_HEAT / salience` re-heats an off-trade `Craft` fact (s = 0.12) to ~0.99 and a `Bed`
  scandal to 0.119 — inverted, over eight times its own asserted bound, and the exact category error
  `02_rumor_pollen.md`'s "Salience is not heat" forbids. At 0.1309 a re-asked `Bed` fact volunteers
  again (`0.1309 × 1.00 > 0.119`) and a re-asked off-trade `Craft` fact does not
  (`0.1309 × 0.12 = 0.0157 < 0.119`): **asked for, not loud.**
- **For a decaying fact it does not touch the ward's air.** Deposit is already
  `air.heat = max(air.heat, held.heat)` on the carrier's next `poll_person`, so a re-heated carrier
  re-warms their ward for free — and a deposit never bumps `stir` (D28), so the re-roll a re-heat
  earns comes from the sweep's next beat like everybody's. A second write here would double-count.
  Test A-19 pins it. (The standing-fact path above is the exception, because a standing fact has no
  deposit path at all.)
- **It is not a verb.** Warming is a consequence, not a decision (`01_facts.md`, "One verb, and why
  repetition does not get one").

### A15. `mint_claim` — the one constructor — and `raise_word`

**`src/knowledge/mint.rs`:**

```rust
/// The **only** constructor for a claimed fact, so no guardrail can be bypassed
/// by writing a `Fact` literal at a call site. Everything an LLM can reach goes
/// through here, and so does the drive-mode poke.
///
/// Unforgeable, in order. `source` is `FactSource::claimed(speaker)` and is not
/// a parameter — a model can mint claims; it can never mint truths. `seeded` is
/// the speaker and nobody else: a claim cannot seat knowledge in other people's
/// heads. `decays` is always true: nothing said aloud becomes a standing fact of
/// the world. The speaker gets an `own` line — the claim *is* in their own
/// words, and without one their own sheet would tell a liar they merely heard
/// it. **And a claim is a template like every other fact (D58)**: the resolved
/// subject's display name in `said` becomes `{subject}`, so a reader who does
/// not know that person reads the role and not the name (the toy's "with your
/// name filed off"), and the mask is the topic's default narrowed to what the
/// sentence can actually garble — `subject` only if the substitution happened,
/// never `place` or `day`, which a free-text claim does not carry. A claim
/// cannot seal itself against drift, including in the mouth of the person who
/// made it up.
///
/// `from` is the mouth that armed them, so `chain()` walks back past the raiser
/// to whoever put the words in their head — the player, in the case this exists
/// for.
pub fn mint_claim(world: &mut World, speaker: &ActorId, topic: Topic, said: String,
                  subject: Vec<ActorId>, from: Option<ActorId>,
                  game_days: Option<f64>) -> Option<FactKey> {
    if !world.knowledge_enabled {
        return None;
    }
    let at = world.characters.get(speaker)?.position_m();
    // The template: the first resolved subject's name → `{subject}`, word
    // boundary and case-insensitive (`actions::replace_name` — the inverse of
    // `text_mentions_name`'s matcher, `actions.rs:289`, and one function with it).
    let (template, subject_named) = match subject.first() {
        Some(who) => match world.characters.get(who).map(|c| c.name().to_string()) {
            Some(name) => crate::actions::replace_name(&said, &name, "{subject}"),
            None => (said.clone(), false),
        },
        None => (said.clone(), false),
    };
    let garble = GarbleMask {
        subject: GarbleMask::default_for(topic).subject && subject_named,
        place: false,
        day: false,
    };
    let own = BTreeMap::from([(speaker.clone(), said)]);   // the words they actually said
    let seeded = BTreeSet::from([speaker.clone()]);
    let key = install_fact(
        world, claim_id(world), topic, template, own, subject, seeded, at, garble,
        true, FactSource::claimed(speaker.clone()), game_days,
    )?;
    world.knowledge.seat_claimant(speaker, key, from, game_days);
    Some(key)
}
```

```rust
/// Whether the sim has put an occasion in front of this actor — the whole of
/// "how does the model know when to use it?", answered structurally rather than
/// by a paragraph of prose: *it knows because the verb is not there otherwise.*
///
/// O(1), because `render_prompt` asks it for everybody and there may be 20,000
/// of them. Read by `render_prompt`'s `has_raise_word` **and** by `raise_word`
/// itself, so advertisement and enforcement cannot come to disagree.
pub fn may_raise_word(world: &World, actor_id: &ActorId) -> bool {
    if !world.knowledge_enabled {
        return false;
    }
    let Some(occasion) = world.knowledge.occasion(actor_id) else { return false };
    // An offered occasion is live whatever its age: the sheet that carries the
    // verb is in flight and the reply must be able to use it (D34).
    if !occasion.offered
        && let Some(now) = world.current_time.map(|time| time.game_days())
        && now - occasion.at_game_days > OCCASION_LIFE_GAME_HOURS / 24.0
    {
        return false;
    }
    let (day, office) = raise_stamp(world);
    world.knowledge.raises_left(actor_id, day, office) > 0
}

/// The bucket the per-office raise cap counts in. `(0, Office::Watch)` with no
/// clock — one bucket for the whole run, so the cap still binds exactly once
/// and a hermetic test can prove `WordAlreadySaid`. `Office::Watch` is the
/// first variant (`clock.rs:36`), so this is the enum's own zero.
fn raise_stamp(world: &World) -> (i64, crate::clock::Office) {
    world
        .current_time
        .map(|time| (time.day, time.office))
        .unwrap_or((0, crate::clock::Office::Watch))
}

/// Coin a proposition, here, now, in your own words — the only path by which a
/// model creates a fact, and everything it creates is a **claim**.
///
/// Every guardrail lives in `mint::mint_claim`, which is the single
/// constructor; this function is the gate, the cap, the collision and the
/// subject resolution, and nothing else.
fn raise_word(world: &mut World, actor_id: &ActorId, args: &Value) -> Result<String, ActionError> {
    // `topic` is **optional** and `said` is not. An unrecognised tag is never an
    // error and neither is a missing one — a missing tag is the limiting case of
    // an unrecognised tag, and the failure direction is deliberately downward: a
    // mis-tagged fact that under-spreads is a shrug, one that becomes a citywide
    // scandal is the bug that would make this verb unshippable. Rejecting the
    // action outright would instead throw the `said` away over three letters.
    let parsed = args_object(args, &["said"], &["topic"])?;
    let said = parse_text(&parsed["said"], "said", PLAYER_SPEECH_MAX_CHARS)?;
    let topic = optional_arg(parsed, "topic")
        .and_then(Value::as_str)
        .map_or(Topic::Talk, Topic::parse_or_talk);

    // Belt and braces: `dispatch` is one table for every actor, so a model can
    // name a verb its own sheet never listed.
    if !may_raise_word(world, actor_id) {
        return Err(ActionError::new(
            ActionErrorCode::NoOccasion,
            "nobody has told you a thing you did not already have, and you have seen nothing the \
             ward has no word for — say it in speech instead",
        ));
    }
    let (day, office) = raise_stamp(world);
    if world.knowledge.raises_left(actor_id, day, office) == 0 {
        return Err(ActionError::new(
            ActionErrorCode::WordAlreadySaid,
            "you have already put one new word about this office — let that one travel, or say \
             this in speech",
        ));
    }

    // Whoever the claim names, resolved against this speaker's own sheet and
    // nobody else: a claim cannot invent a person to be about
    // (`no-procedural-characters` holds here as everywhere). When it names
    // nobody the sim can place, it is about whoever was just asserted at them,
    // which is what `Occasion::subject` is carried for.
    let occasion_subject = world.knowledge.occasion(actor_id).and_then(|o| o.subject.clone());
    let from = world.knowledge.occasion(actor_id).and_then(|o| o.from.clone());
    let mut subject = subjects_named(world, actor_id, None, &said);
    if subject.is_empty() {
        subject = occasion_subject.into_iter().collect();
    }

    let at = world.characters[actor_id].position_m();
    if let Some(ward) = world.ward_at(at) {
        let place = crate::knowledge::mint::area_key_at(world, at);
        let day_of = world.current_time.map(|time| time.day);
        // The collision is on the canonical subject and the raiser's place and
        // day — the same values `install_fact` will stamp (M2 step 16).
        if crate::knowledge::mint::collides_in_air(
            world, ward, topic, subject.first(), place, day_of)
        {
            return Err(ActionError::new(
                ActionErrorCode::WordAlreadyInTheAir,
                "that word is already going round here — you would only be repeating it, which \
                 needs no telling from you",
            ));
        }
    }

    let game_days = world.current_time.map(|time| time.game_days());
    let Some(_key) = crate::knowledge::mint::mint_claim(
        world, actor_id, topic, said.clone(), subject, from, game_days)
    else {
        return Err(ActionError::new(
            ActionErrorCode::InvalidAction,
            "the ward has all the words it can hold just now",
        ));
    };
    // Spent on **success only**, so a refusal cannot burn an occasion the actor
    // never got to use.
    world.knowledge.spend_occasion(actor_id);
    world.knowledge.note_raise(actor_id, day, office);
    Ok(format!(
        "{} starts a word going: \"{said}\"",
        world.characters[actor_id].name()
    ))
}
```
