### 4. `crates/cathedral-sim/src/knowledge/source.rs` — the seal, three ways

Transcribe `01_api.md`'s `source.rs` block, with **one correction**:

> **Correction to `01_api.md`:** `Provenance::ItemAt(ItemId, [f64; 3])` is not implementable.
> `Item` (**item.rs:132–143**) has `id`, `kind`, `quantity`, `metadata` and **no position** — items
> live in `world.items` and are *held* by characters. An item-sourced fact therefore dies when the
> item **changes hands**, which in this sim is what "the item moves" means. Use
> `Provenance::ItemWith { item: ItemId, holder: ActorId }` and
> `FactSource::item_with(item: ItemId, holder: ActorId)`. The authored spelling stays
> `{"item": "fzbn9"}` (03_assets.md); `FactCatalog::seed` resolves the current holder.

```rust
//! Why a fact is true — sealed.

use std::fmt;

use crate::ids::{ActorId, ItemId};
use crate::world::World;

/// Why a fact is true. **Never rendered anywhere** — not a prompt, a projection,
/// a log line, a journal entry or a `Debug` string.
///
/// Sealed three ways rather than one, because a projection-walking test cannot
/// see `EngineMessage::Diagnostic(format!("{fact:?}"))` written in good faith by
/// somebody who has not read this comment: the payload is private to this
/// module, there is no `Serialize`/`Deserialize`/`Display` to reach for, and
/// `Debug` prints a placeholder. A fact says *what*; this says why it is so,
/// and in a quest that is usually the answer the player is looking for.
#[derive(Clone, PartialEq, Eq)]
pub struct FactSource(Provenance);

#[derive(Debug, Clone, PartialEq, Eq)]
enum Provenance {
    /// An author bound it to nothing; it is simply so.
    Authored,
    /// Somebody said it. The only thing an LLM can make (M4), and the whole
    /// safety argument for `raise_word` in one variant.
    Claimed(ActorId),
    /// True while the law holds this person.
    Custody(ActorId),
    /// True while this item is still in this pair of hands.
    ItemWith { item: ItemId, holder: ActorId },
    /// True while this quest phase stands.
    QuestPhase { quest: String, phase: u8 },
    /// Minted from an event and never re-checked.
    Event { kind: String, sequence: i64 },
}

impl fmt::Debug for FactSource {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        f.write_str("FactSource(<sealed>)")
    }
}

impl FactSource {
    pub fn authored() -> Self { Self(Provenance::Authored) }
    pub fn claimed(by: ActorId) -> Self { Self(Provenance::Claimed(by)) }
    pub fn custody(of: ActorId) -> Self { Self(Provenance::Custody(of)) }
    pub fn item_with(item: ItemId, holder: ActorId) -> Self {
        Self(Provenance::ItemWith { item, holder })
    }
    pub fn quest_phase(quest: impl Into<String>, phase: u8) -> Self {
        Self(Provenance::QuestPhase { quest: quest.into(), phase })
    }
    pub fn event(kind: impl Into<String>, sequence: i64) -> Self {
        Self(Provenance::Event { kind: kind.into(), sequence })
    }

    /// A model can mint claims; it can never mint truths. The one bit of
    /// provenance anything outside this module may read.
    pub fn is_claimed(&self) -> bool { matches!(self.0, Provenance::Claimed(_)) }

    /// The mouth a raised word walks back to (M4). `None` for every other route.
    pub fn claimant(&self) -> Option<&ActorId> {
        match &self.0 { Provenance::Claimed(who) => Some(who), _ => None }
    }

    /// Whether the world still bears this out. `false` drops the fact from
    /// `live` and from every holding, which clears it off every sheet on the
    /// next turn with no `forget` and no LLM cooperation.
    ///
    /// M5 wires [`crate::knowledge::invalidate_stale`] into `pollen::sweep`'s
    /// stir beat; until then only tests call it. Every arm has its body here —
    /// M5 edits nothing in this file.
    pub(crate) fn still_true(&self, world: &World) -> bool {
        match &self.0 {
            Provenance::Authored | Provenance::Event { .. } => true,
            // No quest system exists yet, so a phase cannot have advanced.
            // The quest specs bind this when they are rewritten against M5.
            Provenance::QuestPhase { .. } => true,
            Provenance::Claimed(who) => world.characters.contains_key(who),
            Provenance::Custody(who) => world.custody.holds(who),
            Provenance::ItemWith { item, holder } => world
                .characters
                .get(holder)
                .is_some_and(|character| character.holds().contains(item)),
        }
    }
}
```

**Must not derive or implement:** `Serialize`, `Deserialize`, `Display`, a derived `Debug`, `Default`.
`FactSource` must appear in no `EngineMessage`, no `PublicSnapshot` field, and no `format!` outside
this module. `Fact::source` is a **private field**; the only reader is `still_true` and the two
predicates above.

    /// `λ = 0.5^(1/AIR_HALF_LIFE_GAME_HOURS)`. `heat_at_learn` untouched when

    /// golden world stable. The hop loss is charged once, at the hop, so it is
    /// already inside `heat_at_learn` (`02_numbers.md` §2).
    pub fn heat(&self, game_days: Option<f64>) -> f32 {
        let (Some(now), Some(then)) = (game_days, self.learned_on) else {
            return self.heat_at_learn;
        };
        let hours = ((now - then) * 24.0).max(0.0);
        let lambda = 0.5_f64.powf(1.0 / AIR_HALF_LIFE_GAME_HOURS);
        (f64::from(self.heat_at_learn) * lambda.powf(hours)) as f32
    }

Free functions:

```rust
/// **`None` means they have never heard of it at all.** Checks the fact's
/// `seeded` set first — hops 0, heat 1.0, no garble, `from: None` — and returns
/// without reading the carrier store, so a stray row can never be read as a
/// garbled first-hand holding. Every consumer goes through this and nothing
/// else.
///
/// Always call it fully qualified, `knowledge::holds`, and never `use` it: it is
/// one letter from `Character::holds` (the hands, `character.rs:653`) and
/// `Custody::holds` (the law, `custody.rs:305`).
pub fn holds(world: &World, actor: &ActorId, fact: &FactId) -> Option<Held>;

/// The merge rule (`01_facts.md`), all four rows, in one place — and the store's
/// only writer of a carried holding:
///
/// | arrival | effect |
/// |---|---|
/// | fewer hops than held | **replaces** `view`, `from`, `hops`; heat takes the max → `Corrected` |
/// | equal hops | keeps the held `view`; heat takes the max → `Warmed`, or `Unchanged` if the max did not move a whole percent |
/// | more hops | heat takes the max and nothing else changes → `Warmed` / `Unchanged` |
/// | held at hops 0 (i.e. `seeded`) | ignored entirely → `Refused`. A witness cannot be talked out of what they saw |
///
/// Nothing held: `Fresh`. Heat comparisons go through [`heat_pct`], so an
/// arrival that is warmer only in the seventh decimal is `Unchanged`.
/// Over `HOLDINGS_MAX` it evicts coldest first, then most hops, then highest
/// `FactKey` — a total order, so eviction is reproducible.
///
/// **Nothing in production calls this in M1.** M2's pickup does. It ships here
/// because a store nobody can write is a store nobody can test, and because the
/// four rows are the definition of `Held`'s invariants, which M3 relies on.
pub fn learn(world: &mut World, actor: &ActorId, key: FactKey, telling: Telling,
             game_days: Option<f64>) -> Learned;

/// Drop every fact the world no longer bears out, and every holding of it.
/// Returns what died, for a diagnostic. M5 calls it from `pollen::sweep` on
/// every stir beat (half a game hour); in M1 only tests do.
pub fn invalidate_stale(world: &mut World) -> Vec<FactId>;

/// Whether this person can ever carry this fact as news: the subject cannot
/// — they hold it at hops 0 because they were there, or not at all (D15). A
/// **rule and not a number**, so it sits outside the salience product and
/// neither measurement lever (`--pollen-flat`, `--pollen-no-salience`, M2) can
/// remove it (D51). M2's `pickup_chance` returns 0.0 on it; `volunteers`
/// below returns false on it.
pub(crate) fn may_carry(fact: &Fact, who: &ActorId) -> bool {
    !fact.subject.contains(who)
}

/// Whether this holding is warm enough to be said unasked — and therefore
/// whether it may take a heat seat on the sheet, and which register it renders
/// in. `heat × salience`, exactly the product that will drive pickup in M2, so
/// a person repeats a thing on the same terms they caught it. Never for the
/// subject (`may_carry`), and **never for a standing fact** (`!fact.decays`,
/// D52): authored truth is answerable through relevance, never volunteered.
///
/// One function, one home, three callers by M3 (Layer 1's deposit, Layer 2's
/// carrier test, `render_line`'s cold row). M1 uses the topic's **base** band;
/// M2 replaces `world.salience.base(fact.topic)` with
/// `salience::salience_for(world, fact, holder)` at this one site and changes
/// nothing else.
pub(crate) fn volunteers(world: &World, fact: &Fact, holder: &ActorId, held: &Held,
                         game_days: Option<f64>) -> bool {
    if !fact.decays || !may_carry(fact, holder) {
        return false;
    }
    f64::from(held.heat(game_days)) * world.salience.base(fact.topic)
        > f64::from(VOLUNTEER_HEAT)
}
```

`volunteers` returning `false` for a standing fact does **not** hide it from its holders' sheets:
the relevance limb never consults it, and a seeded holder's own line is seated by heat only when
`volunteers` is true — so a `decays: false` fact appears on a sheet when it is asked about (step
13d step 7) and otherwise stays quiet, which is `01_facts.md`'s "a dull fact reaches the player by
being asked for" made literal.

### 8. `crates/cathedral-sim/src/knowledge/mod.rs` — `render_line`, the one place a fact becomes words

```rust
/// Turn one holding into the sentence **this reader** would say. The only place
/// in the crate that turns a fact into words, which is what makes the
/// unknown-people rule a property of the type rather than a promise (D16).
///
/// `None` when the fact is about the reader and they have no `own` line —
/// nobody is told about themselves in the third person (D15).
pub fn render_line(world: &World, reader: &ActorId, key: FactKey, held: &Held,
                   strings: &PromptStrings, game_days: Option<f64>) -> Option<String>;
```

Algorithm, in order — an implementer follows it without choosing:

1. `let fact = world.knowledge.fact(key)?;`
2. `let band = world.salience.hedge_band(fact.topic);` — the **fact's** band, never the reader's
   affinity: a topic is a property of the proposition.
3. `let has_own = fact.own.contains_key(reader);` `let cold = !volunteers(world, fact, reader, held, game_days);`
   `let rung = rung_for(band, held.hops, cold, has_own);` — the table below, one rule.
4. If `rung == Rung::Own` the sentence is `fact.own[reader]`. `own` keys are validated ⊆ `seeded`
   (step 10), and `holds()` answers `seeded` first, so an `own` holder is always hops 0; the own rung
   renders the template **alone** inside `*_hops0_own`'s `%s`, with no other wrapper: a narrator in
   front of a witness's own first-person words swaps person mid-sentence, and that wrapper was
   rejected in all three M0 variants.
5. Else if `fact.subject.contains(reader)` → return `None` (D15).
6. Else the sentence is `fact.said`.
7. Substitute into the sentence, all occurrences, in this order: `{subject}`, `{place}`, `{day}`.
   The `{subject}` replacement is itself already fully rendered — `unknown_person_role`'s two `%s`
   are filled (trade, then ward) before the role goes into `{subject}`, never after, so a trade
   containing `%s` could not be substituted twice (the loader also refuses `%s` in a template).
8. Return `hedge_of(strings, band, rung).replacen("%s", &sentence, 1)`. The rung is substituted
   **last** and exactly once, which is why the loader rejects a template naming `%s` (step 10).

**The rung table** (`03_assets.md` §3, D18): 21 keys, `(HedgeBand, Rung)` → `&strings.know_hedge_*`.
Declare in `knowledge/mod.rs`:

```rust
/// Which rung of the frozen ladder a telling sits on. Seven per band, all
/// measured (`m0_evidence/strings_draft.toml`); M3 adds none.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub(crate) enum Rung { Own, Cold, Hops0, Hops1, Hops2, Hops3, Hops4 }

/// The one precedence rule (D18). The own line wins whatever the heat — D15
/// forbids telling a cold subject-witness `said` about themselves — and that is
/// the one departure from the measured rig, which checked cold first even over
/// `hops0_own`. After it, cold beats every hop count including 0: a hops-0
/// holder of a decaying fact does go cold (M2 step 9), and the measured rig
/// rendered them faded.
pub(crate) fn rung_for(hops: u8, cold: bool, has_own: bool) -> Rung {
    if has_own { return Rung::Own; }
    if cold { return Rung::Cold; }
    match hops { 0 => Rung::Hops0, 1 => Rung::Hops1, 2 => Rung::Hops2, 3 => Rung::Hops3, _ => Rung::Hops4 }
}

/// The 21-cell lookup, by key name. No band-shift: `top`/hops 2 is
/// `know_hedge_top_hops2` ("They say:"), never `default`/hops 1.
pub(crate) fn hedge_of(strings: &PromptStrings, band: HedgeBand, rung: Rung) -> &str {
    use HedgeBand::*; use Rung::*;
    match (band, rung) {
        (Default, Own) => &strings.know_hedge_default_hops0_own,
        (Default, Hops0) => &strings.know_hedge_default_hops0,
        (Default, Hops1) => &strings.know_hedge_default_hops1,
        (Default, Hops2) => &strings.know_hedge_default_hops2,
        (Default, Hops3) => &strings.know_hedge_default_hops3,
        (Default, Hops4) => &strings.know_hedge_default_hops4,
        (Default, Cold) => &strings.know_hedge_default_cold,
        (Top, Own) => &strings.know_hedge_top_hops0_own,
        // … the same seven for `Top` and for `Low`, 21 arms, no wildcard
    }
}
```

`band` is not an input to `rung_for`: the precedence rule is the same in every column, and the band
only chooses which of the three strings a rung renders. The cold predicate is `volunteers` (step 7),
one function, so the deposit gate and the register cannot disagree.

**`{subject}`** — the observer-aware ladder, and the whole of the unknown-people rule. The effective
subject is `held.view.subject.clone().or_else(|| fact.subject.first().cloned())`; a fact with two
subjects names the **first** in `{subject}` and the rest in authored prose or not at all. Extract it
as `pub(crate) fn person_word(world: &World, reader: &ActorId, who: &ActorId, strings: &PromptStrings) -> String`
— M3's `known_from` and M4's journal resolve a teller through the same function, and nothing but it
may turn an `ActorId` into a word on a sheet.

1. `who == reader` → `world.characters[reader].name()`.
2. `world.characters[reader].knows().contains(who)` → `world.characters[who].name()`.
3. the subject has a `LoreProfile` with `occupation_display: Some(trade)` →
   `strings.unknown_person_role` with its first `%s` = `trade` **with only its first character
   lowercased** and its second `%s` = `crate::prompt::ward_label(profile.planning_ward)`
   (**prompt/mod.rs:806**, which already yields `"the Wick Ward"` — it is a bare `fn` today and
   must become `pub(crate) fn`; see step 13g), two sequential `replacen("%s", …, 1)` calls in that

**`{day}`** — relative to the world clock, never a raw number (D10, D16):

/// Two to seven, in words. A digit never reaches a sheet: a number in front of
/// a model is a number it says back.
const DAYS_IN_WORDS: [&str; 6] = ["two", "three", "four", "five", "six", "seven"];

match (world.current_time, fact.day) {
