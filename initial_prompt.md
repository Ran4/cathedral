Look at `docs/reference_image.png`

Create a Rust+bevy (use latest bevy version) project where
we can walk around (quake-style as in WASD+mouse look, but realistic looks!) inside a rendition of this make-belief cathedral.

For textures you can use gpt-image-2, see .env for `OPENAI_API_KEY`

Also, support pressing "f" to toggle flying (no gravity for the player).
