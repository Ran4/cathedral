# The Second Sun — lore and design collection

This folder develops **The Second Sun**, suggestion 1 in
`features/50_cool_suggestions.md`, into a setting pillar that can support
exploration, conversation, ritual, conspiracy, and long-term social play.

The core image remains simple: through the cathedral's western rose, a second,
wrong-coloured sun is visible in a sky that does not exist outdoors. Its light
enters the nave at an impossible angle and makes shadows disagree. The city's
institutions have spent generations learning how to live beside that fact
without ever agreeing what it means.

## Canon contract

This collection uses three confidence levels:

- **Stone** — stable observable fact. NPCs may deny it, but the world should not
  casually contradict it.
- **Glass** — a durable interpretation supported by evidence, yet breakable.
- **Flame** — rumour, testimony, doctrine, dream, or deliberate lie.

The mystery works only if the game preserves uncertainty about ultimate cause.
The player should be able to prove that *something* is happening, discover who
benefits from each explanation, and change the city's relationship to the
phenomenon. They should not receive a final codex entry saying which faction's
cosmology is objectively correct.
